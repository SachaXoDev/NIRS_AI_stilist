# AGENTS.md — Инструкции для LLM и AI-ассистентов

Этот файл описывает архитектурные правила, структуру проекта и соглашения по разработке для AI-агентов (Codex, Claude, Pi, Cursor и др.), работающих с репозиторием **AI-stilist**.

---

## 1. Контекст проекта
- **Название:** AI Stylist (CLOSET.AI).
- **Назначение:** Веб-приложение персонального подбора луков на базе персонального гардероба пользователя с использованием RAG (Retrieval-Augmented Generation).
- **Зона ответственности репозитория:** Фронтенд (Интерфейс чата, визуализация аутфитов, каталог гардероба, клиентская валидация и интеграционные контракты).

---

## 2. Стек технологий
- **TypeScript:** Строгая типизация (`verbatimModuleSyntax: true`). Использовать `import type { ... }` для импорта интерфейсов и типов.
- **React 19:** Функциональные компоненты, хуки (`useState`, `useEffect`, `useRef`).
- **Tailwind CSS v4:** Утилитарные классы оформления. Не создавать громоздкие кастомные CSS классы без необходимости.
- **Lucide React:** Единый набор иконок.

---

## 3. Правила внесения изменений
1. **Сохранение работоспособности сборки:** Перед фиксацией изменений обязательно проверять `npm run build`. Сборка не должна содержать ошибок TypeScript или предупреждений линтера.
2. **Контракт API (`src/services/stylistApi.ts`):** 
   - Не ломать сигнатуру функции `askStylist`.
   - Любое расширение полей ответа бэкенда должно быть обратно совместимо с мок-слоем, чтобы проект запускался автономно без развернутого бэкенда.
3. **Обновление документации:**
   - При изменении пользовательских сценариев обновлять `spec/product/scenarios.md`.
   - При добавлении новых полей в API или модели данных обновлять `spec/tech/architecture.md` и `src/types/index.ts`.
   - Каждое значимое изменение фиксировать в `CHANGE_HISTORY.md`.

---

## 4. Требования к UI/UX
- Темная премиальная цветовая палитра (`bg-neutral-950`, акцент `rose-500` / `pink-500`).
- Адаптивность: интерфейс обязан корректно отображаться как на десктопе (двухколоночный лейаут с сайдбаром), так и на смартфонах (переключение табов Чат/Гардероб).
- Быстрый отклик и анимации индикации размышления стилиста при генерации ответа.
