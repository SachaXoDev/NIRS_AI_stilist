## О проекте

**12 STOREEZ | AI LOOKBOOK** — это интерактивный веб-сервис, позволяющий пользователю оцифровать свою персональную капсулу одежды и получать персонализированные формулы образов от виртуального стилиста.

### Ключевые возможности:
- **Telegram / ChatGPT-стиль диалогов:** многопоточная история переписок, возможность создавать неограниченное число новых консультаций, поиск по чатам и сохранение ответов.
- **Интерактивные лукбук-карточки:** готовые комплекты с описанием баланса фактур, советами по стилизации, сохранением в избранное и шерингом.
- **Полноэкранный каталог капсулы:** удобная галерея вещей с фильтрацией по категориям (верх, брюки, пальто, обувь, аксессуары), составом тканей и поиском.
- **Эстетика 12 STOREEZ:** натуральная палитра (экрю, кашемир, песочный, глубокий контрастный чёрный `#111111`), шрифты `Jost` и `Cormorant Garamond`.
- **Полная мобильная адаптация:** поддержка смартфонов и планшетов, нативная навигация, динамическая высота `100dvh` и модальные шторки (bottom sheets).
- **100% автономность:** работает без внешних серверов на первом этапе (симуляция RAG-пайплайна в клиенте, сохранение в `localStorage`, локальные векторные иллюстрации).
- **Дневная и вечерняя темы:** переключение Light / Dark режима в один клик.

## Быстрый запуск

### Требования
- Установленный **Node.js** версии 18+ или 20+ ([скачать Node.js](https://nodejs.org/))
- Менеджер пакетов **npm** (идёт в комплекте с Node.js)

### 1. Клонирование репозитория
```bash
git clone https://github.com/SachaXoDev/NIRS_AI_stilist.git
cd NIRS_AI_stilist
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```

После запуска терминал покажет ссылку:
```text
  VITE v8.3.4  ready in 150 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

Откройте в браузере **`http://localhost:5173`**.
