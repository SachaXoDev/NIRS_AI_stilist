## 1. Определение с темой проекта

### Формулировка темы
> **«Интеллектуальный диалоговый ассистент-стилист на основе RAG-архитектуры для формирования персонализированных капсульных образов из гардероба пользователя (на примере эстетики 12 STOREEZ)»**

### Проблематика
* **Парадокс полного шкафа:** В среднем до 70% вещей в гардеробе человека не используются, так как владелец забывает о них или не знает правил гармоничного сочетания фактур, оттенков и пропорций.
* **Неэффективность традиционного e-commerce:** Большинство существующих сервисов пытаются продать новые вещи, вместо того чтобы раскрыть потенциал уже имеющихся.
* **Сложность выбора:** Утренний подбор одежды занимает 15–25 минут и часто приводит к однотипным скучным решениям.

### Решение
Веб-сервис с персональным AI-стилистом, который:
1. Индексирует оцифрованный гардероб пользователя (вещи, крой, составы тканей, палитру).
2. Через диалоговый интерфейс формулирует законченные гармоничные образы под конкретные поводы (офис, прогулка, ужин, прохладная погода).
3. Объясняет правила подбора («баланс фактур», «слои», «визуальные якоря»).

## 2. Разработка дизайна и готовый фронтенд

К первой контрольной точке разработан **полнофункциональный автономный фронтенд** (Production-ready web application), соответствующий эстетике бренда **12 STOREEZ**.

### Стек технологий
* **React 19 + TypeScript (Strict Mode)**
* **Vite 8** (мгновенный HMR и быстрый бандлинг)
* **Tailwind CSS v4** (кастомные токены, темная и светлая темы)
* **Lucide Icons** & **Canvas Confetti**

### Ключевые экраны и дизайн-решения:
1. **Эстетика 12 STOREEZ:**
   * Тёплая тактильная природная палитра: алебастр и лён (`#F6F4F0`), мягкий кашемир (`#EFECE6`), слоновая кость (`#FCFAF7`), глубокий эспрессо (`#1E1B18`).
   * Строгая геометрическая типографика (`Inter`), чистые плоские линии, отсутствие визуального мусора.
2. **Раздел «Стилист» (Telegram / ChatGPT мессенджер):**
   * Многопоточная история диалогов со стилистом: список чатов слева с поиском и превью, кнопка `+ Новый`, удаление диалогов.
   * Интерактивные журнальные карточки аутфитов в переписке: галерея задействованных вещей с переходом в детали, обоснование стилиста, рекомендации по носке, шеринг и добавление в избранное с конфетти.
   * Быстрые подсказки-сценарии («Деловая встреча», «Прохладный день», «Выходной в городе», «Ужин в ресторане»).
3. **Раздел «Гардероб» (Полноэкранный каталог капсулы):**
   * Лукбук-сетка оцифрованных вещей (верх, низ, пальто, обувь, аксессуары).
   * Поиск по тканям, цветам и стилям.
   * Модальное окно просмотра вещи с составом и кнопкой быстрого действия: *«Собрать образ с этой вещью»*.
   * Форма добавления нового предмета гардероба.
4. **Адаптивность под мобильные устройства:**
   * Динамическая высота `100dvh` (исключает скачки адресной строки мобильного браузера).
   * Выезжающие мобильные шторки (Bottom Sheets).
   * Поддержка светлой и темной темы с переключением в 1 клик.

3. **Визуализация готового лука:**

## 5. Инструкция по запуску проекта

```bash
# 1. Клонирование репозитория
git clone https://github.com/SachaXoDev/NIRS_AI_stilist.git
cd NIRS_AI_stilist

# 2. Установка зависимостей
npm install

# 3. Запуск веб-приложения
npm run dev
```

Приложение доступно в браузере по адресу: **`http://localhost:5173`**
