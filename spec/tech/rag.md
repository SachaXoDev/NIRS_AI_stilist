# Спецификация RAG-пайплайна для Бэкенда (Команда BM25 & RAG)

Этот документ адресован участникам 2 и 3 (ответственным за классический поиск, векторные базы и генерацию).

---

## 1. Концепция индексации вещей гардероба

Каждая вещь из гардероба пользователя представляется мультимодальным документом:
1. **Лексическое представление (для BM25 участника):**
   - Строка вида: `{title} {category} {color} {material} {brand} {tags_joined}`.
   - Используется Okapi BM25 с кастомной стеммизацией (русский язык: Snowball / pymorphy3).
2. **Семантическое представление (для Dense Retrieval / RAG):**
   - Текстовый эмбеддинг описания + визуальный эмбеддинг фотографии одежды (модели OpenAI CLIP / ruCLIP / Fashion-CLIP).
   - Векторы сохраняются в локальное векторное хранилище (ChromaDB / FAISS / Qdrant) с привязкой к `user_id`.

---

## 2. Алгоритм формирования аутфита (Retrieval + Reasoning)

1. **Query Processing:**
   - Из запроса пользователя извлекаются ключевые сущности (повод, погода, температурный режим, цветовые предпочтения).
2. **Hybrid Search (BM25 + Dense):**
   - Для каждой обязательной категории аутфита (`tops`, `bottoms`, `shoes` и опционально `outerwear`, `accessories`) производится поиск Top-K кандидатов из личного гардероба.
3. **Fashion Rules & Constraint Satisfaction:**
   - Фильтрация по сочетаемости цветов (правило 60-30-10, комплементарные цвета).
   - Проверка погодного соответствия (не надевать открытую обувь в дождь).
4. **LLM Generation:**
   - Системный промпт профессионального стилиста:
     ```
     Ты — опытный персональный стилист высокой моды.
     Пользователь просит: "{user_query}".
     Найденные в его гардеробе вещи: {retrieved_items_json}.
     Собери гармоничный лук из этих вещей.
     Объясни, почему они сочетаются (силуэт, фактура, цвет).
     Дай 2 совета по стилизации.
     Верни ответ строго по JSON-схеме.
     ```
